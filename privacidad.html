Política de privacidad

Menudo Hallazgo · última actualización: 11 de noviembre de 2026

Qué es esta aplicación

«Menudo Hallazgo – estadísticas» es una herramienta de uso personal. La usa únicamente el autor del canal de YouTube Menudo Hallazgo para consultar, desde su propio ordenador, las estadísticas de ese canal. No está pensada ni disponible para otras personas.

Qué datos usa

Con el permiso de su propietario, y solo en lectura, la aplicación consulta a través de las API de YouTube (permisos yt-analytics.readonly y youtube.readonly) las estadísticas agregadas del propio canal: visitas, tiempo de visualización, retención, origen del tráfico, suscripciones e interacciones de sus vídeos. No accede a datos personales de los espectadores ni puede publicar, modificar ni borrar nada.

Dónde se guardan y con quién se comparten

Los datos se descargan y se guardan solo en el ordenador del propietario del canal. No se venden, no se ceden a terceros y no se usan para publicidad. El uso de la información recibida de las API de Google cumple la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de uso limitado.

Cómo retirar el permiso

El propietario puede retirar el acceso en cualquier momento desde la página de permisos de su cuenta de Google.

Esta web

Esta página no usa cookies ni herramientas de analítica. Está alojada en GitHub Pages, que puede registrar datos técnicos de las visitas según la política de privacidad de GitHub.
